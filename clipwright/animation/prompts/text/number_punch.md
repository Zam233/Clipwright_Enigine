# 数字冲屏（number_punch）

## Intent

让一个关键数字成为画面主角：75 分钟、4 小时、3 个版本。

## Semantic constraints

- 数字必须在旁白里出现过，禁止推算/编造
- 主数字字号 ≥ 画面高度的 18%
- 数字单位必须紧邻出现
- 同屏只允许一个主数字

## Composition

主数字居中（可略偏上），单位与说明紧贴其右下；数字用等宽或粗体，
说明文字对比度低一档；背景保持实拍或半透明底板。

## Motion

数字从 0 计数到目标值（0.6–0.9s），带轻微 scale 1.0→1.05→1.0；
单位与说明随后 0.2s 淡入；末段静止 ≥0.6s。

## Anti-patterns

- 无单位裸数字
- 同时冲屏 2 个数字
- 计数过程中数字跳字（不连续）

## Example

旁白「提交人自己合并了，中间隔了七十五分钟」→ 主数字「75」+ 单位「分钟」；
计数 0.8s，落定后静止。

## Style reference

借用「数据冲击 / 苹果发布会风」的数字语言：极大字号、精确对齐、
一个数字独占画面。
