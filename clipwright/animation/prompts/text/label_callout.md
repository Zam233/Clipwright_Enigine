# 标注条（label_callout）

## Intent

给画面上的某个对象贴一个短标签：时间、地点、数字来源、人物身份。

## Semantic constraints

- ≤8 字；必须指向画面中的具体对象或区域
- 不得遮挡人脸与字幕
- 标签数量 ≤2
- 标签内容必须能在旁白或画面里找到依据

## Composition

小尺寸胶囊/直角标签，贴在被标注对象的邻近空白处（距离 16–24px）；
可带 1px 指示线连到对象；背景半透明，文字 24–30px。

## Motion

从锚点侧滑入 8–12px + 描边高亮扫过一次（0.3s）；随后静止。
指示线在 0.2s 内生长出现。

## Anti-patterns

- 悬空标签（观众不知道标的是什么）
- 标签压在字幕上
- 同屏 3 个以上标签

## Example

画面是屏幕录制 → 标签「15:00 提交」贴在提交按钮右上；
1 个胶囊 + 1 条指示线。

## Style reference

借用「工程标注 / 技术图解」的标注语言：细线、短标签、低饱和度。
