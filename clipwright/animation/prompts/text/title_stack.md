# 标题堆叠（title_stack）

## Intent

两到三层信息同时立住：主标题 + 副标题 + 一条细线，用于段落分隔或议题切换。

## Semantic constraints

- 最多 3 层；主标题 ≤12 字，副标题 ≤18 字
- 层间距 ≥12px，整体高度 ≤ 画面 45%
- 副标题颜色饱和度低于主标题
- 文本来自旁白，不新增事实

## Composition

左对齐为主（可居中）；主标题 48–64px 粗体，副标题 28–34px，
细线 2px 宽度 ≤ 主标题宽度；整体位于画面 30–55% 高度区间。

## Motion

主标题先落（0.35s，opacity+translate_y），副标题错峰 0.15s 淡入，
细线最后从左扫过（0.25s）；全部在 1.2s 内完成。

## Anti-patterns

- 三层同样字号（没有层级）
- 标题堆满整屏
- 细线与标题抢对比度

## Example

主标题「四小时」+ 副标题「一个传闻长出了三个版本」+ 一条 2px 细线。

## Style reference

借用「标题堆叠 / 版式海报」的层级语言：字号与权重做层级，装饰只用一条线。
