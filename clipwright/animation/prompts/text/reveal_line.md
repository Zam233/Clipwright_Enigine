# 整句揭示（reveal_line）

## Intent

用一次干净的揭示把结论句立起来，常用于章节开头或论点落地的那一句。

## Semantic constraints

- 单行 ≤14 字；超过就摘要或拆两行
- 文本来自旁白，允许删减不允许新增事实
- 揭示完成后至少静止 0.6s 供阅读
- 默认锚点 center/upper，禁止落入字幕带

## Composition

一行主句（必要时两行），左对齐或居中；可在句首加 3px 竖条作为节奏标记；
整体占用画面高度 ≤35%，四周安全边 ≥10%。

## Motion

遮罩揭示或 16px 上移淡入（0.4–0.6s ease-out）；多词组时错峰 0.06s；
所有关键帧在 1.2s 内完成，之后静止。

## Anti-patterns

- 逐字打字机（信息密度太低，观众等字）
- 长句三行以上压住画面
- 揭示方向与阅读方向冲突（从右往左）

## Example

旁白「先把结论放在前面」→ 揭示「结论先行」；1 个 text 元素，
opacity+translate_y 两个属性，0.5s ease-out，末段静止 0.7s。

## Style reference

借用「文字建筑 / 白板手绘」的干净揭示语言：一个动作只表达一件事，
不留多余装饰。
