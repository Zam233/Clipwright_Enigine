# 关键词强调（emphasis_keyword）

## Intent

把旁白里最关键的那一个词/短语砸在画面上，其余信息让位。它是"视觉重音"，不是字幕的替代品。

## Semantic constraints

- 只允许 1 个主元素（可选 1 个装饰线/底色块）
- 文本必须是旁白的**摘要**，≤10 字，禁止与字幕逐字相同
- 默认锚点 center 或 upper，禁止落入底部字幕带（bottom 160px）
- 数字/时间/专有名词优先原样保留

## Composition

整屏只服务一个词。词居中偏上（画面高度 38–46% 处），左右各留 12% 安全边；
可选一条 2px 强调线压在词下 8px；背景保持实拍可见（不得铺满不透明底）。

## Motion

0.25–0.4s back-out 入场（scale 0.88→1.0，opacity 0→1），落定后一次 4% 轻微弹跳，
随后完全静止；强调线从左到右在 0.25s 内扫过。关键帧覆盖 ≥60% 片段时长，
末段 0.5s 静止。

## Anti-patterns

- 把整句旁白原样搬上来（那是字幕的职责）
- 同时出现 3 个以上强调词
- 持续抖动/无限循环
- 不透明全幅背景遮住实拍

## Example

旁白「这不是在回应什么监管要求」→ 强调词「没有监管要求」；
1 个 text 元素 + 1 条线，center 锚点，scale 入场 0.35s，末段静止 0.6s。

## Style reference

借用代码动画里「大字冲击 / 极简几何」的语言：单一视觉主体、极短动效、
强对比配色；不引入参考图里的文案与数据。
