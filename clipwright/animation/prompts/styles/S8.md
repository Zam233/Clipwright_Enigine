# S8 发布会数字

## 视觉语言

单一大数字主导，单位贴近，入后留读数时间。

## 关键参数倾向

- 配色：#101820 / #F8FAFC / #00A6A6
- 运动：0.6–0.9s 尺度/颜色；计数（仅可数量化）
- 版式：单一大数字；单位贴近
- 渲染路径：drawtext / mg_html

## 适用与回避

- 适用类型：number_punch、mg_data_counter
- 回避类型：quote_block

## 禁止项

- 日期/版本/编号禁从 0 计数
- 禁裸数字

## 使用纪律

- 一个片段只用一个风格模块；要换风格就换片段，不叠加。
- 色值是倾向不是硬编码：透明度/字号/坐标仍由类型提示词与安全区约束。
- 模块声明不可实现的属性时（如粒子、模糊、3D、遮罩）按「本期不落」处理，不得写进 drawtext 关键帧。
