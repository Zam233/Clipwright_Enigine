# 引用（quote）

## Intent

把一句关键引文放大成视觉主体。

## Semantic constraints

- 必须逐字引用原文，不得改写引文内容
- 逐字引用原文，不得改写

## Composition

大字号引文 + 出处小字。

## Motion

引文逐行淡入，引号先出现。

## Anti-patterns

- 改写引文
- 引文超过 3 行

## Example

数据：旁白给出「名言/引文展示」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。
