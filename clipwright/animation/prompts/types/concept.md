# 概念图（concept）

## Intent

概念节点关系网络

## Semantic constraints

- 元素内容必须能在本段旁白里找到依据，不得编造事实或数字
- 文字放不下时先摘要，不允许缩小到不可读或溢出容器
- 至少两个非装饰元素在片段内发生可观测变化（位置/尺寸/透明度）
- 节点文字必须能在旁白里找到依据；超过 18 字先摘要

## Composition

根节点居中/上方，子节点同层级横向或纵向排布，连线呈树/放射结构。

## Motion

根/中心节点先落定（scale 0.9→1 + fade），连线由父向子生长，子节点错峰 0.15s 出现，
当前节点可有一次强调脉冲。

## Anti-patterns

- 元素堆叠导致压字
- 全程静止（关键帧无位移/尺寸变化）
- 编造原文没有的数字或事实

## Example

数据：旁白给出「概念节点关系网络」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。

## Style reference

以下视觉语言来自公开的代码动画风格库（341 种，按语义匹配本类型），只借用**构图/配色/节奏/入场方式**，内容与事实必须仍来自本片旁白：
- **M10 把一个抽象概念、一种情绪做成画面**；画面：没有具体的人和物，用形状、文字、颜色的变化表现一种感觉。

落笔要求：借用其动效语言，但元素内容必须能在本段旁白里找到依据；不引入参考图里的示例数据与文案。
