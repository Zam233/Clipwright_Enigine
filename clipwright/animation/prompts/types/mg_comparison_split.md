# 左右对比（mg_comparison_split）

## Intent

左右对比：A vs B 左右分屏对比：中央渐变分隔线 + 双方错峰入场 + VS 徽章冲击回弹

## Semantic constraints

- 元素内容必须能在本段旁白里找到依据，不得编造事实或数字
- 文字放不下时先摘要，不允许缩小到不可读或溢出容器
- 至少两个非装饰元素在片段内发生可观测变化（位置/尺寸/透明度）

## Composition

整屏单主题：一个主视觉 + 至多两个辅助元素，留白充足。

## Motion

左先右后入场，中央分隔线先绘制；两侧各一条主句。
按模板动效语言走：先主视觉落定，再辅助信息错峰，最后强调一次，末段静止。

## Anti-patterns

- 元素与字幕/人物脸部区域重叠
- 全程静止或只有装饰粒子在动
- 文字超出安全区被裁切

## Example

数据：旁白给出「A vs B 左右分屏对比：中央渐变分隔线 + 双方错峰入场 + VS 徽章冲击回弹」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。

## Style reference

以下视觉语言来自公开的代码动画风格库（341 种，按语义匹配本类型），只借用**构图/配色/节奏/入场方式**，内容与事实必须仍来自本片旁白：
- **F3 分屏对比**；画面：左边以前，右边现在，中间一条线。；关键词：分屏、对比、左右；参考做法：用代码（Canvas 2D）画一段"分屏对比"的动画：左边以前，右边现在，中间一条线

落笔要求：借用其动效语言，但元素内容必须能在本段旁白里找到依据；不引入参考图里的示例数据与文案。
