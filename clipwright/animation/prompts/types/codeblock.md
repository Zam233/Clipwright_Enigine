# 代码块（codeblock）

## Intent

代码片段展示

## Semantic constraints

- 元素内容必须能在本段旁白里找到依据，不得编造事实或数字
- 文字放不下时先摘要，不允许缩小到不可读或溢出容器
- 至少两个非装饰元素在片段内发生可观测变化（位置/尺寸/透明度）
- 逐字引用原文，不得改写

## Composition

单主体大字号 + 出处/语言标记小字；留白 ≥ 40%。

## Motion

文本逐行淡入（translate_y 8→0），装饰引号/代码框先出现，末段静止。

## Anti-patterns

- 元素堆叠导致压字
- 全程静止（关键帧无位移/尺寸变化）
- 编造原文没有的数字或事实

## Example

数据：旁白给出「代码片段展示」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。

## Style reference

以下视觉语言来自公开的代码动画风格库（341 种，按语义匹配本类型），只借用**构图/配色/节奏/入场方式**，内容与事实必须仍来自本片旁白：
- **A2 光标打字**；画面：黑底一个光标，一字一字打，打了又删。；关键词：打字、光标、删掉；参考做法：用代码（Canvas 2D）画一段"光标打字"的动画：黑底一个光标，一字一字打，打了又删

落笔要求：借用其动效语言，但元素内容必须能在本段旁白里找到依据；不引入参考图里的示例数据与文案。
