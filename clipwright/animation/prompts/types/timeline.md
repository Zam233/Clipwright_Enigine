# 时间线（timeline）

## Intent

展示时间轴上的演进（时间点 + 事件）。

## Semantic constraints

- 时间点必须来自原文；无明确年份时用「早期/此后/如今」这类相对词
- 节点文字必须能在旁白里找到依据；超过 18 字先摘要

## Composition

水平轴线 + 节点；标签上下交替避免碰撞；标题一行。

## Motion

轴线先绘制，节点依次落定，当前节点脉冲。

## Anti-patterns

- 编造年份
- 节点标签互相碰撞

## Example

数据：旁白给出「历史演进/项目里程碑，水平时间轴 + 节点」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。
