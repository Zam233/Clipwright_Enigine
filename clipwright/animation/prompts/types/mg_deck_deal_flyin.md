# 卡片飞入（mg_deck_deal_flyin）

## Intent

卡片飞入：video-shotcraft 镜头卡：卡片从右侧带旋转飞入落定 + 标题/说明错峰入场，冲击感缓动 + 末尾 hold

## Semantic constraints

- 元素内容必须能在本段旁白里找到依据，不得编造事实或数字
- 文字放不下时先摘要，不允许缩小到不可读或溢出容器
- 至少两个非装饰元素在片段内发生可观测变化（位置/尺寸/透明度）

## Composition

整屏单主题：一个主视觉 + 至多两个辅助元素，留白充足。

## Motion

卡片从侧下方飞入并轻微旋转归正，错峰 0.15–0.25s。
按模板动效语言走：先主视觉落定，再辅助信息错峰，最后强调一次，末段静止。

## Anti-patterns

- 元素与字幕/人物脸部区域重叠
- 全程静止或只有装饰粒子在动
- 文字超出安全区被裁切

## Example

数据：旁白给出「video-shotcraft 镜头卡：卡片从右侧带旋转飞入落定 + 标题/说明错峰入场，冲击感缓动 + 末尾 hold」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。

## Style reference

以下视觉语言来自公开的代码动画风格库（341 种，按语义匹配本类型），只借用**构图/配色/节奏/入场方式**，内容与事实必须仍来自本片旁白：
- **E1 极简几何**；画面：圆、方、半圆在纯色上滚、落、长出来。；关键词：几何、扁平、色块；参考做法：用代码（Canvas 2D）画一段"极简几何"的动画：圆、方、半圆在纯色上滚、落、长出来

落笔要求：借用其动效语言，但元素内容必须能在本段旁白里找到依据；不引入参考图里的示例数据与文案。
