# 聚光主视觉卡（mg_spotlight_hero_card）

## Intent

聚光主视觉卡：video-shotcraft 镜头卡：暗场聚光圆斑 + 主标题/副标题错峰入场，单一主角动效，末尾 hold 留白

## Semantic constraints

- 元素内容必须能在本段旁白里找到依据，不得编造事实或数字
- 文字放不下时先摘要，不允许缩小到不可读或溢出容器
- 至少两个非装饰元素在片段内发生可观测变化（位置/尺寸/透明度）

## Composition

整屏单主题：一个主视觉 + 至多两个辅助元素，留白充足。

## Motion

光斑扫过 → 主体卡落定 → 辅助信息淡入。
按模板动效语言走：先主视觉落定，再辅助信息错峰，最后强调一次，末段静止。

## Anti-patterns

- 元素与字幕/人物脸部区域重叠
- 全程静止或只有装饰粒子在动
- 文字超出安全区被裁切

## Example

数据：旁白给出「video-shotcraft 镜头卡：暗场聚光圆斑 + 主标题/副标题错峰入场，单一主角动效，末尾 hold 留白」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。
