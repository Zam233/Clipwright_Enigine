# 折线图（line_chart）

## Intent

展示趋势变化。

## Semantic constraints

- 至少 3 个数据点且来自原文
- 数值必须来自本段旁白或 web_context；没有数值就不要编造，改画结构关系

## Composition

坐标轴 + 折线 + 数据点。

## Motion

折线沿路径绘制，数据点依次出现。

## Anti-patterns

- 两点连线冒充趋势
- 编造数据点

## Example

数据：旁白给出「趋势变化，带面积填充 + 数据点」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。

## Style reference

以下视觉语言来自公开的代码动画风格库（341 种，按语义匹配本类型），只借用**构图/配色/节奏/入场方式**，内容与事实必须仍来自本片旁白：
- **F1 图表生长**；画面：柱子一根根长出来，数字跳动，再连成线。；关键词：图表、数字、生长；参考做法：用代码（Canvas 2D）画一段"图表生长"的动画：柱子一根根长出来，数字跳动，再连成线

落笔要求：借用其动效语言，但元素内容必须能在本段旁白里找到依据；不引入参考图里的示例数据与文案。
