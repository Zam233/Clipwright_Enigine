# 层级（tree）

## Intent

层级/分类结构：一个根 + 若干子项。

## Semantic constraints

- 子项必须是同一层级的并列项
- 根节点来自原文主题词
- 节点文字必须能在旁白里找到依据；超过 18 字先摘要

## Composition

根节点居中上方，子节点横向排布，连线呈树形。

## Motion

根节点先落定，连线向下生长，子节点错峰出现。

## Anti-patterns

- 根节点与子节点语义重复
- 子项跨层级混排

## Example

数据：旁白给出「分类/组织结构/目录树，根节点 + 子节点」。
生成要点：3–5 个元素，主视觉居中偏上，一条主结论小标题；入场错峰 0.15–0.3s，
关键帧覆盖 ≥ 60% 片段时长，末段 0.6s 静止；不出现原文之外的事实。

## Style reference

以下视觉语言来自公开的代码动画风格库（341 种，按语义匹配本类型），只借用**构图/配色/节奏/入场方式**，内容与事实必须仍来自本片旁白：
- **F2 关系图**；画面：人和人之间的箭头一条条画出来，箭头上写着那句话。；关键词：节点、箭头、关系图；参考做法：用代码（Canvas 2D）画一段"关系图"的动画：人和人之间的箭头一条条画出来，箭头上写着那句话

落笔要求：借用其动效语言，但元素内容必须能在本段旁白里找到依据；不引入参考图里的示例数据与文案。
